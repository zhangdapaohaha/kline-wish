# KLineWish · K线许愿

> 会生长的 K 线蜡烛 —— Windows 桌面动效控件，直播 / 节目「许愿涨」氛围神器

## 这是什么

一个常驻桌面的迷你蜡烛图：K 线以**阶跃方式**实时生长（暴涨猛拉、偶尔下砸插针、周期性清零重开），可拖拽到屏幕任意位置。适合直播、路演、节目现场当「涨跌氛围组」。

- **绿涨**：底部钉死，阶跃向上生长
- **红跌**：顶部钉死，阶跃向下砸
- **真实蜡烛形态**：实体 + 上下影线，周期结束自动重开
- 颜色对齐币安 / OKX：绿 `#0ECB81`，红 `#F6465D`

## 功能

- 🕯️ 阶跃式生长动画（不是线性漂移）：静止蓄力 → 0.12s 猛窜 → 高位停留 → 偶发砸盘 → 疯狂拉回
- 📌 反向插针：涨势中偶发变红下砸（泊松长尾，越极端概率越低），一闪即拉回
- 🚀 涨破天际 / 跌穿屏幕：偶发整屏穿刺动画（菜单可关，默认开）
- 🖱️ 左键拖动 / 滚轮调波动幅度 / Shift+滚轮调实体宽 / 双击暂停
- 📋 右键菜单：趋势切换、尺寸（实体宽滑条无级调节 5~30px）、颜色反转（红涨绿跌）、始终置顶、跟随指定窗口
- 🪟 零依赖：纯 tkinter + ctypes，单文件源码，Python 3.10+ 直接跑

## 快速开始

**不想装环境**：直接下载 [`dist/KLineWish.exe`](dist/KLineWish.exe) 双击即用（单文件便携版，无需 Python）。

**有 Python 环境**：双击 `启动 KLineWish.bat`，或：

```bat
pythonw arrow_pet.py
```

## 菜单说明

| 菜单项 | 作用 |
|---|---|
| 下跌 ↓ / 上涨 ↑ | 切换趋势（显示的是「点了会变成什么」，非当前状态） |
| 尺寸 ▸ | ↺ 重置尺寸 / 实体宽滑条（5~30px，拖动或滚轮）/ 波动幅度 4 档 / 涨破天际·跌穿屏幕开关 |
| 颜色反转 | 默认 涨绿跌红；开启后 涨红跌绿（照顾传统行情软件的红涨绿跌配色） |
| 始终置顶 | 开关窗口置顶（关闭后可被其他窗口覆盖） |
| 跟随窗口 ▸ | 与指定应用同图层（可被覆盖、随目标关闭而退出）；列表可识别软件与网页 |
| 退出 | 关闭 |

## 自己构建

```bat
pip install pyinstaller
pyinstaller KLineWish.spec --noconfirm
```

产物在 `dist/KLineWish.exe`（spec 已裁剪 Tcl/Tk 资源，成品约 8.7MB）。

## 文件

| 文件 | 说明 |
|---|---|
| `arrow_pet.py` | 单文件源码（全部逻辑，约 1100 行） |
| `KLineWish.spec` | PyInstaller 打包配置 |
| `icon.ico` | 蜡烛图标 |
| `启动 KLineWish.bat` | Python 版无控制台启动器 |
| `dist/KLineWish.exe` | 打包好的便携版 |

## 技术备忘

- 纯 tkinter + ctypes（Win32 API），无第三方运行时依赖
- 自绘深色菜单（ModernMenu）：悬停保持 / 脱离收起 / 滑条控件
- 「跟随窗口」用 `SetWindowLongPtrW(GWLP_HWNDPARENT)` 绑定目标窗口实现同图层
- 顶层窗口通过 PID + 标题枚举自身获取 HWND（`GetParent(windo_id)` 返回 0，不可用）
